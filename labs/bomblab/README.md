## 常用调试命令

```bash
# 反汇编整个炸弹
objdump -d bomb > bomb.asm

# 查看字符串
strings bomb

# 启动调试（建议单用户模式）
gdb ./bomb

# 常用 gdb 命令
(gdb) break phase_1
(gdb) run < input.txt
(gdb) disas phase_1
(gdb) info registers
(gdb) x/10x $rsp
(gdb) stepi
(gdb) nexti
(gdb) continue
```

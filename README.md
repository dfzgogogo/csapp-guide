# CSAPP 学习记录

本仓库记录学习 *Computer Systems: A Programmer's Perspective*（CSAPP）的过程，包括：教学大纲、学习进度、章节笔记、Lab 实践和外部资源。

## 学习目标

- 系统理解计算机系统各层次如何协作
- 掌握底层机制（数据表示、汇编、链接、内存、并发等）
- 独立完成 CSAPP 官方 Lab

## 仓库结构

```
csapp-guide/
├── README.md          # 本文件：仓库入口与路线图
├── syllabus.md        # 教学大纲与周计划
├── progress.md        # 实际学习进度与复盘
├── resources.md       # 外部资源汇总
├── notes/             # 每章学习笔记
├── labs/              # 各 Lab 的代码、思路与总结
└── exercises/         # 课后练习与自写示例代码
```

## 快速开始

1. 打开 `syllabus.md` 查看整体学习路线。
2. 根据当前进度，在 `progress.md` 中打卡。

4. 做 Lab 时，在 `labs/<lab-name>/README.md` 中记录思路与关键解法。
